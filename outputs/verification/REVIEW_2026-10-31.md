Actual native exports and screenshots are still required. Four read-only DAX queries and 12 independent context fixtures are prepared in `powerbi/queries`; they include zero/BLANK, no/multiple models, missing actuals, June and future-only filters.
2. **Uncertainty is weak during high demand.** Only 713 of 1,487 high-demand hours fall inside the nominal 80% bands: **47.95%**, versus 78.58% overall. All 25 missing test actuals form one contiguous gap around the fall clock change. **Fixed:** the case study, notebook, model card, career wording and Power BI diagnostics now expose these limitations. The frozen experiment was not retuned.
3. **Several Power BI source edge cases could mislead.** Empty counts and zero-hit coverage needed different handling; default time ordering was not pinned. **Fixed within source-checked scope:** count/coverage guards, chronological sorts, active relationship/cardinality metadata, row-major tab order, title alt text and stale-threshold fallback. Native engine/render behavior is still pending. See `powerbi/STATIC_AUDIT.md`.
4. **Headless notebook execution lost charts.** The first Linux pass ran without cell errors but had zero embedded figures. **Fixed and rerun:** the notebook explicitly selects the inline renderer and refuses success unless all seven figures are retained. The final Linux run contains seven embedded charts. Earlier insufficient/failed harness receipts are retained for traceability.
